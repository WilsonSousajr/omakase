# M2 Identity: Omakase's look on Liquid Glass — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Mac app gets its own visual identity: a palette, a type scale,
glass tinting and the Today/Focus layout. They are explored as SwiftUI mockups
on real Liquid Glass, recorded in `docs/design-system-apple.md`, and then
applied to the shell (the split view, sign-in, Today, the icon and the accent
colour). M3 builds its screens on this identity rather than on a placeholder.

**Architecture:**
- The tokens live in **OmakaseFeatures** under `Sources/OmakaseFeatures/Design/`.
  - They are plain values: sRGB triples as `0xRRGGBB` literals, paired for
    light and dark.
  - A thin bridge turns each pair into a dynamic `Color`, through
    `NSColor(name:dynamicProvider:)` on macOS and `UIColor(dynamicProvider:)`
    on iOS.
- The mockups are `#Preview` galleries in `Sources/OmakaseFeatures/Mockups/`.
  - They take plain values, not models, so M3 can wire the same views.
- The app target owns what only macOS has: the asset catalog, the `.icon`,
  and `AccentColor`.

**Tech Stack:** SwiftUI on macOS 26 (`glassEffect`, `GlassEffectContainer`,
`.glassProminent`), Swift Testing, Icon Composer and XcodeGen.

**Spec:** `docs/superpowers/specs/2026-09-25-macos-client-design.md`, L170-175
(window structure and glass) and L202-206 (visual identity).
**Depends on:** M1 merged to `develop` (#92-#98).

## Decisions already made (with the user, 2026-09-25)

- **Palette:** sumi, meaning warm ink-and-paper neutrals that carry the web's
  monochrome restraint, plus **one** signature accent, **shu** (vermilion).
- **Timer phases are tinted.** Focus is shu, the short break matcha, the long
  break ai (indigo). This follows IDEA.md L433; the web's monochrome timer is
  not carried over.
- **Type:** SF Pro, the system font, with Omakase's own named scale, so
  Dynamic Type works and no font is bundled. The web's signature section label
  (small, semibold, uppercase, tracked) is kept.
- **Mockups:** SwiftUI `#Preview`s only, with no HTML stage, because only real
  glass shows tinting and refraction.

## Global Constraints

- The limits and rules from M1's plan still apply:
  - macOS 26.0 minimum, Swift language mode 6
  - `Features → Store → API`, and **no new package**, so
    `check-layers.sh` is untouched
  - function body ≤ 20 lines, CC ≤ 10, nesting ≤ 2, file ≤ 500 lines, no
    `print`
- **The tokens count toward Features' coverage (≥ 90%).** Only `*View.swift`

- The tokens are platform-neutral, because OmakaseFeatures is shared with

- No `Color(red:…)`, hex literal, bare `.padding(<number>)` or bare font size
  outside `Design/` once Task M5 lands. The SMOKE grep checks this.
- Every task follows AGENTS.md:

  - branch `type/<N>-<slug>`
  - commits `type(#N): …`
  - test-first

## Review Focus

1. **Text contrast in both appearances.** Expected: `ink` and `inkMuted` are
   ≥ 4.5:1 on `background` and on `surface`, in light and in dark. Pinned in
   Task M1: `textMeetsAAOnEverySurface`.
2. **The prominent button's white label on shu.** On macOS, `.glassProminent`
   draws a white label on the tint. Expected: ≥ 4.5:1 in both appearances,
   which is why dark shu is `#D0462C`: `#E4583C` measured only 3.65. Pinned in
   Task M1: `whiteLabelReadsOnShu`.
3. **Accents as UI marks** (the timer ring, priority marks, the focus tint).
   Expected: ≥ 3:1 on `background` (WCAG 1.4.11), in both appearances. Pinned
   in Task M1: `accentsAreVisibleOnBackground`.
4. **The bridge resolves the right half.** Expected: the `Color` from a token
   resolves to the light triple under `.aqua` and to the dark triple under
   `.darkAqua`. Pinned in Task M1: `bridgeResolvesPerAppearance`.
5. **An unknown priority string** (the server adds one, or `TaskRecord` holds
   an old value). Expected: it gets the neutral `inkMuted` mark and never
   crashes. Pinned in Task M1: `unknownPriorityIsNeutral`.

```swift
/// An sRGB colour, written as the hex a designer reads.
///
///     RGB(0xC8402A).luminance   // WCAG relative luminance, 0...1
public struct RGB: Equatable, Sendable {
    public let red: Double
    public let green: Double
    public let blue: Double

    public init(_ hex: UInt32) {
        red = Double((hex >> 16) & 0xFF) / 255
        green = Double((hex >> 8) & 0xFF) / 255
        blue = Double(hex & 0xFF) / 255
    }

    /// WCAG 2.x relative luminance.
    public var luminance: Double {
        0.2126 * Self.linear(red) + 0.7152 * Self.linear(green) + 0.0722 * Self.linear(blue)
    }

    /// WCAG contrast ratio, 1...21, in either argument order.
    public static func contrast(_ lhs: RGB, _ rhs: RGB) -> Double {
        let (high, low) = (max(lhs.luminance, rhs.luminance), min(lhs.luminance, rhs.luminance))
        return (high + 0.05) / (low + 0.05)
    }

    private static func linear(_ channel: Double) -> Double {
        channel <= 0.04045 ? channel / 12.92 : pow((channel + 0.055) / 1.055, 2.4)
    }
}
```

`ColorBridge.swift` adds `DesignColor.color`. It is a
`Color(nsColor: NSColor(name: nil) { appearance in … })` that picks the dark
triple when `appearance.bestMatch(from: [.aqua, .darkAqua]) == .darkAqua`,
and the `UIColor { traits in … }` equivalent under `#if os(iOS)`. The test
resolves the `NSColor` under each appearance with
`NSAppearance(named:)!.performAsCurrentDrawingAppearance`.

`TypeScale` defines the named styles over text styles:
- `display`: `.largeTitle`, light, with `displayTracking` 6. Used for the
  wordmark.
- `title`: `.title2`, semibold.
- `headline`, `body` and `caption`.
- `sectionLabel`: `.caption`, semibold.

`Text.sectionLabel()` applies the label style (uppercase, tracking 1.5,
`inkMuted`).

`Spacing` is a 4-pt grid: `xs 4, s 8, m 12, l 16, xl 24, xxl 32`. `Radius`
is `small 8, medium 12, large 16`. `WindowSize.minimum` is 520 × 420, M1's
frame.

  the remaining tasks and a capture field.
- **The capture panel** is a floating neutral glass field with a
  destination hint.
- **Priority** is a leading mark: a 3-pt capsule in the priority colour.
  It is never a row fill.
